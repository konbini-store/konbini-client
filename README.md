# Konbini Market
The first official client for the Konbini app store, designed in the style of Android Market 1.5.

## What is Konbini?
Konbini is an app store for Android 1.0 and up, built for both FOSS and proprietary apps. It’s fully static and relies on JSON files instead of databases. And unlike F-Droid, you get complete freedom over where files live, whether that’s the Internet Archive or your home server. The main repo doubles as an APK archive [wink]

## Getting started
Get the latest APK from the [Releases page](https://github.com/konbini-store/konbini-client/releases) and you're good to go! \
You can also always build it yourself.

### System requirements
Right now the only requirement is an Android 1.5+ device. Note that the tablet UI is not implemented at this point.

## Building
Build it with the latest version of Android Studio. Nothing else needed.
